\section{Model Grid and Per-Benchmark Task Counts}
\label{sec:supp-grid}

\paragraph{Seventeen instruction-tuned models across four families.}
The main evaluation grid comprises instruction-tuned checkpoints across four model families: (1) \textbf{Qwen}: Qwen2.5-0.5B, Qwen2.5-1.5B, Qwen2.5-3B, Qwen2.5-7B, Qwen2.5-14B, Qwen2.5-32B, and Qwen2.5-Math-7B; (2) \textbf{Phi}: Phi-3-medium, Phi-3.5-mini, and phi-4; (3) \textbf{OLMo}: OLMo-2-7B, OLMo-2-13B, and OLMo-2-32B; (4) \textbf{Mistral}: Mistral-7B-v0.3, Ministral-8B, Mistral-Small, and Mathstral-7B.
DeepSeek-Math-7B-Instruct appears in the twelve-model per-token sweep subset outside the seventeen-model boundary map.
\textsc{SWE-bench Verified} evaluates a separate eight-model grid of repository coding models, including the four-model Qwen2.5-Coder size ladder ($1.5$B, $7$B, $14$B, $32$B).

\paragraph{Scored versus shipped task counts.}
Evaluated task counts per benchmark are: \textsc{MATH-500}, $500$ tasks ($6{,}000$ model--task pairs across the twelve per-token models; $60$-task blind human anchor set; $20$-task earlier shared block); executed code oracle, $492$ freshly generated \textsc{HumanEval}/\textsc{MBPP+} solutions; full \textsc{MATH}, $600$ scored tasks ($5{,}000$ shipped); \textsc{GSM8K}, $500$ scored ($1{,}319$ shipped); \textsc{GSM8K-Platinum}, $500$ scored ($1{,}209$ shipped); \textsc{Putnam-AXIOM}, $236$ scored ($522$ shipped); \textsc{Putnam-Variations}, $265$ scored; \textsc{Omni-MATH}, $500$ scored in the seven-model Qwen sweep ($\sim 4{,}400$ shipped); and \textsc{SWE-bench Verified}, $500$ tasks.
