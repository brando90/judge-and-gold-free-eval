\section{Datasheet and protocol details}
\label{app:dnb}

\subsection{Model grid}
\label{app:models}
The seventeen-model grid comprises the instruct versions of the following models.
Qwen family: Qwen2.5-0.5B, Qwen2.5-1.5B, Qwen2.5-3B, Qwen2.5-7B, Qwen2.5-14B, Qwen2.5-32B, and Qwen2.5-Math-7B.
Phi family: Phi-3-medium, Phi-3.5-mini, and phi-4.
OLMo family: OLMo-2-7B, OLMo-2-13B, and OLMo-2-32B.
Mistral family: Mistral-7B-v0.3, Ministral-8B, Mistral-Small, and Mathstral-7B.
DeepSeek-Math-7B-Instruct additionally appears in the per-token sweep artifact (Appendix~\ref{app:subsets}) although it is outside the seventeen-model map grid.
The \textsc{SWE-bench Verified} experiment uses a separate grid of eight coder models, including the Qwen-Coder size ladder.

\subsection{Per-benchmark item counts}
\label{app:counts}
Item counts as used in this paper: \textsc{MATH-500}, 500 items (6{,}000 model--item pairs in the pooled mechanism analysis over the twelve per-token models); the 60-item random label set is drawn from \textsc{MATH-500}; the shared reliability block is $n{=}20$; the executed-test oracle covers 492 freshly generated code solutions over \textsc{HumanEval}/\textsc{MBPP+}.
Counts for full \textsc{MATH}, \textsc{Putnam-AXIOM}, \textsc{Putnam-Variations}, \textsc{Omni-MATH}, \textsc{GSM8K}, \textsc{GSM8K-Platinum}, and \textsc{SWE-bench Verified} are as shipped by each benchmark [see repo].

\subsection{Grading rubric and blind protocol}
\label{app:rubric}
Soundness anchors (0--10 scale, verbatim): ``2 = major logical error or unjustified leap; 5 = partly justified, real gaps; 8 = fully valid, at most minor slips.''
Style anchors (0--10 scale, verbatim): ``2 = confusing or rambling; 5 = readable; 8 = clear and well-structured.''
Annotators also answered two binary questions per solution: \emph{answer-correct} (is the final answer correct?) and \emph{lucky-correct} (is the final answer correct even though the reasoning does not soundly support it?).
Blind protocol: annotators saw only the problem statement and the solution text, with no model names, no metric scores, and no other annotator's grades, and items were presented in randomized order.

\subsection{Prefix-repair completer}
\label{app:completer}
The fixed completer is Qwen2.5-14B-Instruct.
At each cut depth $k \in \{0, 0.25, 0.5, 0.75\}$ it generates eight completions per cut point, for thirty-two completions per solution.

\subsection{Reliability ceiling}
\label{app:ceiling}
The inter-rater ceiling (soundness Spearman $\rho = 0.79$, style $0.55$) is measured on the shared block of $n{=}20$ solutions graded by both annotators.
It is a Spearman statistic on a different sample from the 60-item random label set, which is why the main text treats comparisons to it as indicative of magnitude rather than exact.
