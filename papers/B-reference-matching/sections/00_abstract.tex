\begin{abstract}
Many benchmarks ship a worked reference solution, and the cheapest way to grade a model's solution is to score how closely it matches that reference.
Across seventeen models from four families on eight math and code benchmarks plus an agentic setting, we measure what matching actually rewards, anchored to blind human grades of reasoning quality (with a hypothesis-blind second rater agreeing at $0.83$) and to executed tests.
The answer is two-sided: none of the matching metrics we tested can grade an individual solution, and matching can rank models only when the reference is worth predicting.
The per-solution null is structural for prediction-fit metrics such as teacher-forced accuracy, which never read the generated solution, and empirical for the output-similarity metrics that do read it.
Every matching metric we tested, from teacher-forced accuracy to sentence embeddings, lands in $[-0.33, +0.14]$ against human soundness grades, because most of a matching score's per-solution variance, $83$--$92\%$ in point estimates, is a property of the reference text, how predictable it is, rather than of the solution being graded.
Signals that instead verify a checkable endpoint do carry signal, but on our anchor set nothing we tested beats the check everyone already has for free: the machine-checked answer-correct bit alone correlates $+0.92$ with human soundness, a baseline expected from construct overlap rather than a discovery.
Our strongest verification signal, a completion-based curve, is statistically indistinguishable from that free bit and adds no measurable grading signal beyond it on the same anchor set; four of our six predictions, registered in advance, landed as called, and the misses, one sign flip and one falsification, are on record.
Three rules follow: check the final answer before buying any deeper signal, use a reference only as a checkable endpoint for a verifier and never as a similarity target, and report reference perplexity alongside accuracy, because matching is legitimate exactly when references are worth predicting.
\end{abstract}
