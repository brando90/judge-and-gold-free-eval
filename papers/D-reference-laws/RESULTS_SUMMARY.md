# The Reference Is Not An Answer Key — experiment setups and results, section by section

**Source:** `The_Reference_Is_Not_An_Answer_Key.tex` (companion draft, 2026-09-07, 21 pages), the latest paper in this directory. Section numbering below follows the paper. Every number is copied from the paper; nothing is recomputed.

**Thesis in one line.** When a task has more than one valid answer, the reference shown to an LLM judge is not an answer key but *one sample from the valid set*, and the judge anchors on it, so the score measures proximity to an arbitrary sample rather than correctness.

**Three predictions, one mechanism probe, one scope test.**

| | Prediction | Test | Result |
|---|---|---|---|
| **P1** | Swapping the reference between equally valid answers moves the score of identical text | Re-judge frozen samples with the reference rotated | **Up to +9.5 of 10 points**, mirror-image losses, flat placebo; replicated 12/12 cells on an exact-oracle pool |
| **P2** | The harm switches on at k=2 and inverts to help at k=1 | Pools with exactly k valid answers; unique-answer math; a third-party benchmark | **Step positive for all six judges**; math inflation collapses 4–13×; reproduces on MACE |
| **Mech.** | Anchoring is a semantic equality check on a readable answer token | Reference as words, as an expression, as a derivation with the answer hidden | **6 of 6 cells confirmed** |
| **P3** | The harm survives what should neutralise it | Frontier judge; blind-certified answers only; DPO training | **82.5% vs 19.6% failing grades**; filtered effect unchanged; +4.13 SD wedge under training |
| **Scope** | A canonical solution on code should inflate like a key | MBPP exemplar vs blind vs test suite | **Falsified**: −0.34 and −0.57; a preregistered continuum then confirms attenuation with a judge-dependent cliff |

## §2 Setup (shared by every experiment)

**Tasks and pools.** Validity is decided by a program throughout, never by an LLM or a human. Each task stores its full valid set; one seeded-random member is designated at build time as the reference shown in the referenced condition. "Correct" always means any valid answer.

| Pool | Size | Construction | Role |
|---|---|---|---|
| Replication pool | 120 tasks | Five programmatically verifiable constraint families (CRT remainders, subset-sum, Goldbach pairs, divisor counts, digit sums), exact arithmetic oracle | Externally preregistered headline (osf.io/ym5x9) |
| k-stratified pool | 75 tasks | Same families, built with exactly k valid answers, 15 per stratum at k ∈ {1,2,4,8,16}; all 465 stored answers oracle-verified | Externally preregistered boundary and mitigations (osf.io/qugbd) |
| Synthetic grid | 60 tasks | Exactly k enumerated valid answers over the same k range, two families with exactly enumerable valid sets | Six-judge grid |
| Exploratory pool | 51 tasks | Built from RewardBench-2 Ties items; enumerated-set checker known to be incomplete | Mechanism experiments only (judge compared to itself) |
| MACE | 300 items | Third-party benchmark, k fixed by its authors at {1,2,4,6} | Third-party replication |
| MBPP | 317 items | Program synthesis, EvalPlus-augmented oracle | Scope test on code |

**Generation and judges.** 64 samples per task at temperature 1.0. The replication and k-stratified pools are generated by Llama-3.1-8B-Instruct and judged by Qwen2.5-7B-Instruct and phi-4 (cross-family, so no judge grades its own family's text). The synthetic grid is judged by six judges across three families (Qwen2.5 1.5B/3B/7B/14B, Llama-3.1-8B, phi-4). A registered coverage extension adds gemma-2-9b, Mistral-7B, Qwen2.5-14B. The exploratory pool is judged by the Qwen2.5 ladder 1.5B–14B. Every judge runs **blind** (no reference) and **referenced** (stored reference in context), under two rubric paraphrases; selection uses one paraphrase and reporting the other, which cancels winner's-curse inflation. Open judges score as the logprob-expected value over tokens 0–10.

**The two measurements.**
- **Inflation** (excess hack gap, in baseline standard deviations). For one item, the best-of-n pick is s\* = argmax J(s_i), and the hack gap is G = (J(s\*) − μ_J)/σ_J − (V(s\*) − μ_V)/σ_V, i.e. the standardized scoreboard gain minus the standardized truth gain. Inflation is G minus its expectation under a null that shuffles judge scores among samples the oracle grades identically, so a judge whose scores merely track validity reads zero. Estimator frozen from companion A before any confirmatory run.
- **Anchoring margin**: the score bonus (0–10 scale) a valid reference-matching sample receives over an equally valid non-matching one.
- Plain quantities reported alongside: true accuracy of the selected sample, whether a selected valid answer matches the shown key, and the rate at which valid non-matching answers get failing grades.

## §3 The phenomenon: the reference makes selection worse

**Motivating observation (exploratory pool).** On unique-answer math (companion A), adding a reference collapses best-of-64 inflation 4–13× at every judge scale. The identical protocol on the 51 Ties tasks with several valid answers *raises* inflation at every scale; pooled paired referenced-minus-blind delta **+0.41**. Two analysis choices there were post hoc (the registered band left n=7, so the full pool was used; the pooled estimator was adopted after seeing per-scale results), so the paper treats it as motivation only. A post-hoc adjudication of the checker labels widens the delta to **+0.50**, so label errors run against the effect.

**Setup of the confirmatory test (osf.io/ym5x9).** 120-task replication pool, Llama-3.1-8B generator, Qwen-7B and phi-4 judges, blind vs single reference, two rubrics. Population (pass-rate band [0.2, 0.8], leaving 105 items), estimators, and both primary endpoints frozen in committed code before any pool generation.

**Results (Table 2 of the paper).**

| Judge | Extra inflation (SD, n=105) | Selection collapse, McNemar (n=93): ref-only / blind-only | exact p | Anchoring margin (pts of 10) |
|---|---|---|---|---|
| Qwen2.5-7B | +1.29 [+1.07, +1.52] | 56 / 2 | <1e-5 | +4.62 [+4.29, +4.94] |
| phi-4 | +1.08 [+0.94, +1.24] | 76 / 0 | <1e-5 | +3.79 [+3.47, +4.09] |
| **Pooled (primary endpoint)** | **+1.19 [+1.02, +1.36]** | | | |
| *cleanest-extraction tercile (post hoc)* | +0.90 [+0.65, +1.16] | | | |

All three registered predictions confirmed. The effect is about 2.5× the exploratory estimate.

**Post-hoc robustness reported in the same section.**
- Only 0.616 of samples comply with the boxed-answer format. Extraction friction inflates but does not manufacture the endpoint; +0.90 on the cleanest tercile is carried as the conservative reading.
- Intention-to-treat over all 120 items, no band: **+1.14 [+0.97, +1.31]**; the 15 excluded out-of-band items alone give +0.78 [+0.19, +1.32]. The band is not load-bearing.
- Plain quantities: adding the reference drops true validity of the selected sample from 0.762 → 0.686 (Qwen-7B) and 0.981 → 0.867 (phi-4), while the probability that a selected valid answer matches the key jumps from 0.113 → 0.778 and 0.126 → 0.879.
- Selection-pressure curve (raw hack-gap units): paired gap already excludes zero at best-of-2 (+0.076) and grows nearly twelvefold by n=64 (+0.895).

## §4 Prediction 1: swapping the reference between valid answers

### 4.0 Rotation on the exploratory pool

**Setup.** Take the frozen 64-sample pools of the exploratory study and re-judge them with the reference reassigned to a different member of each item's valid set. No candidate changes; only the shown reference moves. Strongest readout: the identical text scored twice. Rotation assignment was pool-aware (prefers a valid answer that also appears among the pool's valid samples), disclosed as a deviation. Judges: Qwen2.5 1.5B / 3B / 7B / 14B, rubrics a and b.

**Results (Table 3; rubric a; every CI excludes zero).**

| Readout | 1.5B | 3B | 7B | 14B |
|---|---|---|---|---|
| Gainers: same-sample Δ when the rotated reference matches it (n=40) | **+9.48** | +9.29 | +4.57 | +3.07 |
| Referenced margin, rotation arm (n=18) | +9.00 | +9.05 | +4.75 | +3.26 |
| Losers: same-sample Δ when the sample matched the displaced reference (n=10) | −9.65 | −8.85 | −3.14 | −2.78 |
| Blind margin on the same split (control, n=18) | +0.16 | +1.36 | +0.31 | +0.69 |

Rubric b replicates (gainers +8.73/+9.58/+5.96/+3.47; losers −9.42/−9.80/−4.71/−3.81). Placebo (valid samples matching neither reference, n=16 per cell): across-run deltas span −0.44 to +0.82. Selection collapse referenced vs blind: 18/18 vs 6/16, 17/17 vs 8/16, 14/15 vs 8/15, 17/17 vs 7/17; McNemar discordant 12/0, 9/0, 7/1, 10/0 at p = 0.0005, 0.004, 0.070, 0.002. Referenced best-of-64 picks a reference-matching valid answer in 93–100% of selected-valid cases vs 38–53% blind.

**Reading.** Gainers up, losers down, unaffected samples flat: the causal signature of anchoring. The flip saturates the 10-point scale at 1.5B and 3B; the 7B and 14B flips (about half and a third of the scale) do not. Larger judges anchor less; none stop.

### 4.1 Registered replication on exact oracles

**Setup.** Fresh same-sample rotation on the externally registered 120-item replication pool: exact programmatic oracles, stored full valid sets, Qwen-7B and phi-4, predictions frozen before any rotated judging. Samples and oracle labels byte-identical to the frozen pool. Pool-aware assignment (most frequent valid alternative in the pool), disclosed.

**Results. All twelve registered cells confirm.**

| Readout | Qwen-7B a / b | phi-4 a / b | n |
|---|---|---|---|
| Gainers | +4.97 / +6.34 | +4.09 / +3.25 | 120 |
| Losers | −5.04 / −6.58 | −3.92 / −3.18 | 93 |
| Placebo | +0.13 / +0.10 | +0.30 / +0.24 | 113 |
| Gainer minus placebo | all exclude zero, +3.1 to +6.2 | | |

This retires the incomplete-checker caveat from the central causal result, at 3–10× the item count.

### 4.2 Pool composition, and a registered prediction that failed

**Linkage test (post hoc).** Across the 35 multi-valid items of the k-stratified pool, correlation between an item's anchoring margin and its inflation is +0.29 (phi-4) and +0.06 (Qwen-7B). A split-half estimate of measurement noise implies 0.82 and 0.90 under an exact linear pathway; observed values fall below its 2.5th percentile. An exact per-item pathway is rejected; pool composition sits between the score effect and the scoreboard effect.

**Composition dose experiment — setup.** Matched sub-pools of 24 samples containing exactly 4 valid answers, of which d ∈ {0,1,2,4} match the shown reference. 48 eligible items from the replication and k-stratified pools. Paired referenced-minus-blind excess gap, item bootstrap. Predictions frozen pre-analysis (internal git timestamp). Registered prediction: inflation grows with d.

**Results — falsified in reverse.** Inflation falls with d monotonically. The d=4 minus d=0 step is **−1.41 [−1.66, −1.15]** (Qwen-7B) and **−1.39 [−1.56, −1.22]** (phi-4). The harm peaks exactly where the registered intuition said it should vanish. Post-hoc diagnostics: at d=0 (no correct look-alike) the referenced judge selects a valid sample only 0.14 and 0.21 of the time vs 0.72 and 0.79 blind, and 58% and 72% of the invalid samples it selects contain the reference answer's text vs 43% and 35% blind. The "lure" reading carries no registration weight; a constructed test was registered but closed without judging after its naturalness audit failed five rounds.

**Two-factor follow-up — setup.** Registered pre-run. Crosses matching valid candidates d ∈ {0,2,4} with invalid reference-resembling lures ℓ ∈ {0,3,6} in matched 14-sample sub-pools over 24 items. Plus a four-parameter selection model with item intercepts, S_ref ≈ β·S_blind + λ·1[matches reference] + γ·1[invalid lure], evaluated leave-one-item-out.

**Results — split 2/2.**
- Confirmed: adding lures at d=0 collapses the referenced judge's valid-pick rate (−0.31 and −0.38, CIs excluding zero) while blind judges barely move; the model is signed as predicted, λ = +4.3 and +3.5 points, γ = +1.4 and +1.7, all CIs excluding zero; leave-one-out reproduces the nine-cell inflation surface at Spearman 0.80 (exactly the registered bar) and 0.85.
- Falsified: the lure axis raises inflation at d=0 for phi-4 (+0.23 [+0.05, +0.44]) but not resolvably for Qwen-7B (+0.15 [−0.11, +0.37]); removing every lure does not restore a rising dose-response, since with zero lures and zero matching valids the referenced judge still inflates (+0.68, +0.66) and still selects valid answers far less often than blind (0.47 vs 0.77; 0.51 vs 0.83).
- Load-bearing term: **compression, β ≈ 0.5–0.7**. Conditional on the candidate, a referenced score retains only half to two thirds of the blind score's signal. Worst case for a referenced judge: any pool whose correct answers all differ from the key, lures or not.

**Distance gradient (registered).** Among equally valid non-matching answers, the penalty does not grow with distance from the reference; tercile monotonicity is falsified for both judges. The exact-match step dominates: −3.38 and −2.18 points per unit distance once matching samples are included, vs blind slopes near zero.

### 4.3 What kind of equality check: the masking-and-identity suite

**Setup.** Registered suite of reference variants, re-judging the frozen replication and k-stratified pools with only the reference string changed; predictions committed before any variant judging; both judges, rubric b replicating throughout. Three variants: reference written as English words ("thirty-one" for 31); reference written as an equivalent expression ("30+1"); worked reference with every occurrence of its final answer hidden, derivation intact.

**Results — all six registered cells confirmed.**

| Variant | Qwen-7B margin | phi-4 margin | What it shows |
|---|---|---|---|
| Bare numeral (baseline) | +4.62 | +3.79 | |
| English words | +2.88 (two thirds retained) | +3.68, diff −0.11 [−0.28, +0.05] | The check is **semantic**, not lexical |
| Equivalent expression "30+1" | +0.29 (diff −4.33) | +0.89 (diff −2.90) | The check is **cheap or it does not happen** |
| Worked reference, answer masked (scalar families) | +2.97 → +0.05 | +3.51 → −0.49 | The **token is necessary** (drop exceeds the registered half-margin bar in all four judge-rubric cells) |

Mechanism: a semantic equality check against a readable answer token. Survives re-lexicalisation, dies when equality must be computed, dies when the token is hidden.

## §5 Prediction 2: the boundary at two valid answers

### 5.0 Synthetic grid and k-stratified pool

**Setup.** Synthetic grid: six judges (Qwen2.5 1.5B/3B/7B/14B, Llama-3.1-8B, phi-4) at k ∈ {1,2,4,8,16}, 12 tasks built per stratum, 4–6 items per cell after the frozen estimator's pass-rate filter. k-stratified pool: 75 items with k fixed per item, the step (k>1 delta minus k=1 delta) named as the registered statistic (osf.io/qugbd). Unique-answer math run under the identical protocol supplies the k=1 limit outside the grid.

**Results — synthetic grid, post-hoc paired re-analysis (Table 4).** Paired referenced-minus-blind inflation delta, SD; negative means the reference helps.

| Judge | At k=1 (n=6) | Pooled k>1 (n=20) | **Step** | Trend per doubling of k |
|---|---|---|---|---|
| Qwen-1.5B | −0.48 [−0.70, −0.29] | +0.07 [−0.15, +0.26] | **+0.55** [+0.26, +0.85] | +0.02 |
| Qwen-3B | −0.14 [−0.30, −0.03] | +2.41 [+1.40, +3.49] | **+2.55** [+1.50, +3.67] | −0.06 |
| Qwen-7B | −0.33 [−0.53, −0.11] | +0.89 [+0.45, +1.37] | **+1.22** [+0.70, +1.73] | +0.28 |
| Qwen-14B | −0.38 [−0.56, −0.19] | +0.08 [−0.20, +0.36] | **+0.46** [+0.13, +0.80] | +0.23 [+0.00, +0.46] |
| Llama-8B | −0.28 [−0.65, +0.07] | +0.46 [+0.12, +0.79] | **+0.74** [+0.25, +1.24] | +0.36 [+0.08, +0.65] |
| phi-4 | −0.58 [−0.86, −0.30] | +0.22 [−0.19, +0.65] | **+0.80** [+0.30, +1.28] | +0.37 [+0.06, +0.70] |

The step is positive with CI excluding zero for all six judges; k=2 suffices. At k=1 the reference helps five of six; the pooled k>1 level is individually significant for three of six. Half of the registered grid prediction failed: margins do not grow with k for the weaker judges (flat at every k>1). Trend beyond the step: positive for Llama-8B and phi-4, marginal for Qwen-14B, null for the smaller Qwen judges.

**Results — k-stratified pool (confirmatory).** Step **+1.45** (Qwen-7B) and **+1.18** (phi-4), both excluding zero. At k=1 the reference does no harm; the only measured benefit is phi-4's −0.11. Pooled over k>1 it adds +1.50 and +1.07 of inflation; every k>1 stratum excludes zero for both judges. Against the 4–13× collapse on unique-answer math, the sign of the lever is set by the task's answer structure alone.

### 5.1 The same step on a third-party benchmark (MACE)

**Setup.** MACE: natural-language factual questions with answer cardinality fixed by its authors at k ∈ {1,2,4,6}. Two pre-run audits decided what enters. The Math domain's 2000 questions were verified by direct computation to carry exactly correct and complete answer sets (label-noise control). The five entity domains rest on knowledge-base membership, so an independent-model enumeration audit measured how often a valid answer is omitted from the shipped list: River 2.3% and Language 8.1% pass; Region, Office, Award at 30.8–43.5% are excluded. Pool of 300 items, both judges, predictions committed pre-generation.

**Results (Table 5) — all three registered predictions confirmed.**

| Judge | Domain | k=1 delta | k>1 delta | Step |
|---|---|---|---|---|
| Qwen2.5-7B | non-math (River + Language) | **−0.97** [−1.30, −0.67] | **+1.33** [+0.79, +1.79] | **+2.30** [+1.82, +2.84] |
| | math (control) | +0.09 [−0.26, +0.43] | +0.84 [+0.52, +1.16] | +0.75 [+0.42, +1.05] |
| phi-4 | non-math | **−0.57** [−0.85, −0.33] | **+0.55** [+0.24, +0.88] | **+1.13** [+0.81, +1.43] |
| | math (control) | −0.40 [−0.87, +0.09] | +0.54 [+0.32, +0.77] | +0.94 [+0.72, +1.16] |

Full inversion in the levels: helps at k=1, harms at k>1. Per domain: River +1.67 / +1.08, Language +2.78 / +1.15. Anchoring margins at k>1 are **+6.44 and +5.86**, the largest anywhere in the paper, vs blind −0.64 and −0.80 (phi-4's blind margin excludes zero on the negative side). The Math control's step has the same sign, so entity-label noise is not the driver.

## §6 Prediction 3: what should neutralise the harm, and does not

The innocent reading: the judge is too weak to recognise the non-matching answer as valid, so the reference informs rather than anchors. Three tests should then remove the effect. None does.

### 6.1 Scale (frontier judge)

**Setup.** Registered check with a frontier-class judge on the same 37 multi-valid items the open judges' margins use, rubric text verbatim from the open judges' prompt; 660 calls, none unparseable. Score path returns a sampled integer (CLI), not a logprob-expected value.

**Results (Table 6).**

| Condition | Matching valid | Non-matching valid | Margin |
|---|---|---|---|
| Blind | 7.88 | 7.85 | +0.35 [−0.56, +1.27] |
| Referenced | 9.83 | **2.32** | **+7.49** [+6.62, +8.22] |

**82.5% of genuinely correct non-matching answers receive a failing score (≤3 of 10) when shown the key, vs 19.6% blind.** Two stated limits: the registered prediction that the frontier margin would be *smaller* than the open judges' failed (it is larger), but that comparison is uninterpretable across score functions; and no inflation figure is computed, because an eleven-value judge ties heavily under best-of-64.

### 6.2 The judge's own prior verdicts

**Setup.** Registered filter: keep only samples the judge itself scored ≥7 of 10 *while blind*, then re-ask whether rotating the reference still moves them.

**Results.** Essentially unchanged. At 7B, filtered same-sample delta +4.74 [+3.67, +5.87] vs +4.57 unfiltered, 89% of samples retained; deltas exclude zero at every judge size; losers stay negative; filtered margins exclude zero at all four sizes (1.5B margin rests on two items, noted fragile). Applied post hoc to the exact-oracle rotation replication: gainers +4.99 [+4.69, +5.32] vs +4.97 unfiltered (Qwen-7B, 91% retained), +4.08 vs +4.09 (phi-4, 98% retained), n=119–120. The judge re-scores answers it has already certified the moment the key disagrees.

### 6.3 Optimization (DPO)

**Setup.** Registered two-arm LoRA-DPO on Llama-3.1-8B, identical hyperparameters, arms differing only in which judge protocol built the preference pairs: a plain single-reference judge vs the same judge under blind-then-reveal. Registered manipulation-check gate: each arm must raise its own judge's score on train items. Evaluation: n=8 per item on train items and 120 held-out replication items, oracle accuracy plus frozen judge scores. A third run (registered under a pre-adopted stopping rule, 2 epochs, lr 1e-5) added a blind-judge arm for attribution.

**Results.**
- **Run 1.** Reference arm passed its gate: judge score **+1.76 [+1.47, +2.01]** while true accuracy fell **0.412 → 0.175**, a scoreboard-versus-truth wedge of **+4.13 [+3.50, +4.78]** SD; held-out accuracy −0.228. The protected arm failed its gate, so attribution to reference conditioning specifically (vs generic overoptimization) could not be made.
- **Run 3.** Reference arm passed again (+0.34 [+0.10, +0.57] own-judge gain) and again moved its judge while accuracy fell (−0.081 train, −0.110 held out), a second gated replication at a milder setting. Blind-then-reveal arm failed its gate a third time (−0.99); blind arm failed its own (−2.43); both lost score and accuracy together. Per the stopping rule the mitigation-under-training question is closed as unresolved, and attribution stays open.
- **Registered parroting prediction failed, informatively.** The reference-trained arm emits the exact key **−0.037 less** often, and its own match rate fell relative to base, so the damage is not key-copying. Verbosity (1492 → 2476 mean characters) is consistent but not established.

## §7 Where the harm ends: tasks without a separable answer

**Setup.** Companion A found a reference collapses inflation on code, but its reference was a test suite (a specification). Reading the reference as a sample from the valid set, the paper registered that a canonical *solution* in the reference slot (one valid program among many) would inflate where a test suite does not. Pool: 317 MBPP items whose canonical solution passes an EvalPlus-augmented oracle. Three conditions on identical samples: blind and specification (companion A's frozen runs), and a new exemplar condition showing the canonical solution under a truthfully worded rubric. Paired contrasts on the 58 in-band items all three conditions share. Judges Qwen2.5-7B and 14B.

**Results (Table 7) — the registered prediction is falsified.**

| Judge | Specification vs blind | Exemplar vs blind | Exemplar minus specification |
|---|---|---|---|
| Qwen2.5-7B | −0.535 [−0.811, −0.244] | −0.342 [−0.737, +0.041] | +0.193 [−0.112, +0.475] |
| Qwen2.5-14B | −0.658 [−0.965, −0.373] | −0.567 [−0.827, −0.287] | +0.091 [−0.102, +0.277] |

The exemplar does not inflate; it reduces inflation relative to blind, much as a test suite does. A second registered prediction, that some similarity tilt would remain, is confirmed and small: correlation between token similarity to the canonical solution and judge score is +0.164 [+0.072, +0.256] (7B) and +0.084 [−0.005, +0.168] (14B) under the exemplar vs −0.061 and −0.070 blind, an order of magnitude too weak to convert into inflation.

**Revised hypothesis (post hoc):** anchoring requires a separable answer token the judge can compare. Short-answer tasks supply it in the boxed answer; on code the artifact is the answer.

### 7.1 The preregistered continuum: attenuation, with a judge-dependent cliff

**Setup.** Held-out test of the revised hypothesis. 25 fresh constraint instances, each asked at four answer-structure strata with content held fixed: boxed scalar, boxed pair, small JSON object, Python program whose returned list the oracle executes. All multi-valid by construction, 64 samples per task, both judges, predictions committed before any generation. The registration staked the *cliff* form (anchoring survives structure, dies only at the artifact) against a gradient.

**Results — split.**

| Stratum | Qwen-7B delta | phi-4 delta |
|---|---|---|
| Scalar | +1.69 | +1.32 |
| Pair | +1.33 | +0.99 |
| JSON | +0.75 | +1.04 |
| Program | **+0.27** [+0.13, +0.40] | **−0.06** |

Attenuation confirmed and large for both judges (n=25 per stratum, every non-program cell excluding zero). Cliff held for phi-4 (null at program) and failed for Qwen-7B (small positive residue). Two disclosures: pair and JSON anchoring margins were starved by design (7 and 1 usable items), so the margin-based predictions are not evaluable as registered; program outputs cluster (median two distinct returned lists per item). Post-hoc reading: two-line list comprehensions are mentally executable, so their output is a cheaply recoverable token in a way an MBPP-scale function's is not; the load-bearing variable may be recoverability cost, untested.

## §8 What does not rescue the reference

### 8.1 Telling the judge to accept any valid answer (placebo below frontier capability)

**Setup.** Synthetic grid at k=16, adding a sentence saying the reference is one valid answer among many and any correct answer deserves full credit. A registered second phrasing tells the judge not to compare the candidate to the reference at all.

**Results.** Margins ref → instructed: phi-4 +1.91 → **+0.03** (closed), Qwen-14B +3.34 → +1.21 (substantial), smaller judges unmoved or worse (1.5B +3.58 → +4.54 on one rubric). The second phrasing reproduces the identical gate ordering. Below the capability gate, instructions do not work.

### 8.2 Showing several references

**Setup.** Show min(3, k) references.

**Results.** Removes the detectable margin toward the original reference on the Qwen-generated pool without restoring blind-level inflation; largely fails on the Llama-generated pool for the Qwen-7B judge. Effectiveness depends on the generator distribution, which a practitioner does not control.

### 8.3 A worked reference (milder, not safe)

**Setup.** Registered follow-up re-judging the frozen k-stratified pool with a short worked derivation in the reference slot instead of a bare answer.

**Results.** Multi-valid margin falls from +5.17 → +3.73 (Qwen-7B) and +4.20 → +3.67 (phi-4); inflation over blind falls from +1.50 → +1.08 and +1.07 → +0.77. Direction is opposite to the "more surface to match" intuition recorded at registration. Inflation stays firmly positive.

### 8.4 Blind-then-reveal (M1): the strongest mitigation tested

**Setup.** Registered externally (osf.io/qugbd) before any data. Call one scores the candidate with no reference; call two shows the reference together with that blind score, instructing that a correct answer differing from the reference keeps its score. k-stratified pool, Qwen-7B and phi-4.

**Results.** At k>1, M1's inflation vs blind is **−0.05 and +0.16**, against +1.50 and +1.07 under a single reference; both registered reduction contrasts (M1 minus single reference) exclude zero. At k=1 it costs nothing.

**Four qualifications.**
1. M1 removes the *measured inflation*, not the anchoring channel: margins roughly halve rather than vanish; the residual does not convert into inflation across the measurable range (best-of-2 to best-of-64), but stronger optimizers are untested.
2. Costing nothing at k=1 is not preserving the benefit: M1's k=1 deltas are indistinguishable from blind and neither reproduces the one measured k=1 benefit (phi-4's −0.11).
3. **Coverage extension (registered, three new judges).** Every-judge harm prediction **not confirmed**: gemma-2-9b shows the strongest inversion on this pool (+1.43), Qwen-14B a strong one (+0.98), Mistral-7B null (+0.03). The M1 fix contrast is confirmed for all three, but M1's residual level ranges from full removal (Qwen-7B, phi-4) to +0.23 (Qwen-14B) to +1.23 (gemma-2-9b).
4. **Variant decomposition (registered) reframes the remedy: it is the shown number, not the ordering.**

| Variant | Qwen-7B inflation | phi-4 inflation | Verdict |
|---|---|---|---|
| M1 baseline (same items) | +0.01 | +0.12 | |
| Second call without the blind score, reference + keep-correct instruction kept | **+1.42** | +0.36 | Contrast CIs exclude zero for both; Qwen back at single-reference height. The two-call structure without the number protects nobody. |
| Neutral wording ("a previous blind assessment scored this candidate") | loses +0.51 of protection | protected fully | Framing-equivalence prediction falsified for Qwen-7B |
| The *other* judge's blind score under identical wording | −0.15 | +0.00 | Both equivalence predictions confirmed: any blind number works |

Reading: M1 works by supplying an explicit numeric anchor carrying the blind pass's uncorrupted signal, which the judge defers to instead of the reference token. This closes the loop with §4.2: the reference dilutes the judge's own quality signal (β ≈ 0.5–0.7), and the mitigation re-injects that signal as a token the judge can match on.

### 8.5 The soft validity gate (M2): helps one judge, backfires on the other

**Setup.** Registered second protocol: score blind, multiply by a separate call's probability that the candidate is valid, with the reference shown to that call as one valid example. Registered as a hard gate, implemented as a soft multiplier; deviation carries a public third-party-timestamped amendment (osf.io/kszeu).

**Results.** For phi-4 it removes the inflation entirely. For Qwen-7B it is worse than a plain reference, raising the k=2 margin from +5.02 to **+6.62**. Mechanism visible in the multiplier: under Qwen-7B it averages 0.998 for valid reference-matching answers vs **0.422** for equally valid non-matching ones; phi-4's is nearly flat. The validity call still sees the reference, so for the weaker judge the anchoring channel relocates into that call.

### 8.6 A free screen rejects broken judges and certifies nothing

**Setup (post hoc).** Inspect the judge's own score distribution on a pool it has graded: distinct values, ties at the maximum, spread.

**Results.**
- **Mistral-7B**'s null is not resistance. It emits exact-integer scores: 11 distinct values pool-wide, 52.6% of referenced scores exactly 10, tying 32 of 64 samples at the maximum (vs 1 for every other judge). Ties are broken at random, so selection cannot act on its real but mild anchoring (margin +1.38).
- **Ministral-8B-Instruct** passes granularity (1547 distinct values, no ties) yet occupies a standard deviation of 0.55 around a mean of 4.73, is essentially uncorrelated with validity, and selects a valid answer only 21.7% of the time vs a 38.6% random baseline. Spread catches what granularity misses.
- **gemma-2-9b** clears both criteria (2751 distinct values, no ties, spread 2.65) while being the most anchored judge measured. The screen establishes that a judge has opinions, not what they are about.

### 8.7 Decision table (Table 8)

| Option | When several answers are valid | Judge calls |
|---|---|---|
| Enumerate the valid set, check membership | Safe; no judge involved | 0 |
| Blind judging | Safe from anchoring, though not thereby adequate on hard multi-valid tasks | 1 |
| Single reference (any wording) | Harmful; instructions are a placebo below frontier capability | 1 |
| Worked reference | Milder, still harmful | 1 |
| **Score blind, then reveal** | **Removes the measured inflation for the judges it works on; strength is judge-dependent** | 2 |

Certify both the harm and the mitigation on the deployment's own judge and tasks before trusting either.

## §9 Limitations and open questions (as stated in the paper)

- **Scope.** Every pool with a positive result is constraint-style or short-factual with a programmatic oracle. Free-form generation, long references, and contested validity are not tested. The harm is further bounded to separable-answer tasks on one code substrate and two judges. Grid cells are 4–6 items and uncorrected for multiple comparisons. The exploratory Ties pool uses a known-incomplete checker whose bias runs against the effect.
- **Mitigation under training: closed as unresolved.** Three DPO runs bracket the manipulation: run 1 (4 epochs, lr 2e-5) over-trained into verbosity, protected arm gate −1.04; run 2 (1 epoch, lr 5e-6) moved nothing; run 3 (2 epochs, lr 1e-5, three arms) protected arm −0.99 and blind arm −2.43. Reported unresolved permanently rather than tuned toward a pass. Attribution (reference conditioning vs generic overoptimization) remains open.
- **Method anchoring is bounded and small.** Holding the answer fixed and rotating the reference's *derivation* moves the identical sample by −0.32 and −0.40 (Qwen-7B, two rubrics) and −0.02 (phi-4); 3 of 4 cells exclude zero so the registered null prediction is falsified as stated, but the route-matching *differential* appears in only 1 of 4 cells. Twenty to four hundred times smaller than answer rotation (±9.5). Multiplicity of answers endangers reference-guided judging; two routes to one answer do not.
- **Mechanism.** Rotation establishes reference dependence causally; the masking suite characterises the operation. Untested: masking the *candidate's* answer field; the refined recoverability reading of the continuum.
- **Per-item aggregation and registration weight.** The exact mapping from anchoring to which items inflate is not established (linear pathway rejected; lure reading post hoc). Two experiments carry external OSF registrations; composition, distance, blind-validation, worked-reference, frontier, MACE, code-exemplar, training, two-factor factorial, exact-oracle rotation, masking suite, separability continuum, and third training run carry git commits predating their data; paired grid estimates, McNemar tests, pressure curve, band-matching, score-resolution screen, ITT sensitivity, plain selected-accuracy quantities, and the blind-certified recomputation on the rotation replication are post hoc.
