\section{Verdict stability under label subsampling}
\label{app:subsample}
At $n$ labels resampled from the anchor set (500 draws), the fraction of draws reproducing the full-sample verdict under fixed rules (convict if style partial $> 0.30$; pass if soundness partial $> 0.40$ and style partial $< 0.20$): sabotage conviction $0.93/0.98/1.00$ at $n = 20/30/40$; honest frontier pass $0.96/1.00/1.00$; 1.5B-blind conviction $0.65/0.84/0.94$; boundary configurations (1.5B referenced, 14B blind) remain below $0.7$ until $n \ge 50$.
Full table: \texttt{papers/analysis/label\_subsampling.md}.
