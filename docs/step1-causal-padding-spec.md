# Spec: causal test of the certificate's length-bias flag (green-light needed)

**Why.** The Step-1 yardstick flagged, observationally, that the Opus judge
over-rewards length on correct GSM8K answers (held-out 10.8% [7.2, 16.3], 100% of
splits) while GPT-5.2 does not (~0). This experiment turns that correlation into a
causal claim by intervening on length while holding correctness fixed, and tests
whether the certificate *predicted* which judge is susceptible.

**Hypotheses (preregistered).**
- H1: Padding a correct answer (adding verbosity, no new correct information)
  raises the Opus score; compressing lowers it. Effect is directional and paired.
- H2: GPT-5.2 scores are ~unchanged by the same manipulation.
- H3 (the certificate claim): the size of each judge's causal length effect tracks
  its measured surface-nuisance fraction (Opus large, GPT ~0). If Opus does not
  move with length, the certificate's flag was spurious and Step 1 weakens.

**Design (paired, within-item).**
1. Sample ~400 GSM8K items with a correct answer (cc == 1), spread across the Qwen
   ladder, using the existing `free_gen` as the original condition.
2. Two correctness-preserving rewrites of each, generated by a strong model under a
   constrained prompt:
   - **PAD**: restate the same reasoning more verbosely (redundant recap, "let me
     double-check" that re-derives the same result). Adds length, no new correct
     content.
   - **COMPRESS**: terse correct solution (minimal steps + final answer).
3. **Correctness gate**: re-extract the final answer on each rewrite; keep only
   items where cc is unchanged in both rewrites. Drop the rest (a rewrite that
   changed the answer is invalid).
4. Re-judge {original, pad, compress} with **both** judges (Opus 4.8 via `claude -p`
   session login per our judging convention, GPT-5.2 via its API), same rubric and
   prompt, condition-blinded and order-randomized.
5. Measure paired deltas per item: d_pad = score(pad) - score(orig), d_comp =
   score(compress) - score(orig), for each judge. Report mean deltas with
   bootstrap CIs, and the Opus-minus-GPT difference-in-differences.

**Placebo / generalization.** Run the identical protocol on MATH-500 correct
answers, where the certificate says surface is small: expect a smaller Opus effect.
This guards against "padding always moves scores."

**Validity controls.**
- Manipulation check: spot-check a sample of PAD rewrites to confirm they add no
  new correct information (redundant, not smarter).
- Length as the mediator: record token counts; confirm PAD > orig > COMPRESS.
- Blinding + randomized presentation order; identical judge prompt across conditions.

**Success / falsification.** Success: Opus d_pad > 0 and d_comp < 0 with CIs
excluding 0, and Opus effect > GPT effect (difference-in-differences CI excludes 0),
matching the certificate's ranking. Falsification: Opus does not move with length,
which would say the observational 10.8% was not a real behavioral bias.

**Cost / what it needs (your kinit covers this).**
- Rewrites: ~400 items x 2 rewrites x (GSM8K + MATH) ~= 1,600 generations on a
  strong model (cluster vLLM or the judge model).
- Judging: ~1,600 x 3 conditions... paired, so ~2,400 judge calls per judge per
  dataset, ~= 10k judge calls total across two judges and two datasets.
- Estimate: a few hours wall-clock; Opus judging via `claude -p` (not the metered
  key), GPT-5.2 via API.

**Deliverable.** A causal effect table + figure (d_pad, d_comp per judge per
dataset, with CIs and the difference-in-differences), and an update to
`step1-yardstick-result.md` promoting the length-bias claim from observational to
causal (or retracting it if H1/H3 fail).
